一个工具，覆盖全部配音需求

常见问题

你可能想知道

YiziVoice 免费吗？

工具本身完全免费，仅需在设置中填入自己的 MiMo API Key。MiMo-TTS 系列语音生成模型免费调用；MiMo-ASR 语音转文字模型与 MiMo-2.6 系列文本模型为付费模型，使用时需账户有余额。注册时填写邀请码，可额外获得 10 元体验金。

支持哪些平台？

提供 Windows、macOS 与 Linux（AMD64）桌面应用，请从 GitHub Releases 下载，三个平台同一入口。macOS 为未签名的 universal DMG，首次打开若被 Gatekeeper 拦截，右键选择「打开」或执行 xattr -cr /Applications/YiziVoice.app 即可。Linux 提供 deb 与 AppImage：deb 为推荐方式，sudo dpkg -i YiziVoice_<版本>_amd64.deb（或 sudo apt install ./YiziVoice_<版本>_amd64.deb 自动补依赖）；AppImage 下载后 chmod +x 即可运行，属实验性格式。

克隆音色需要多长时间？

录音 20 秒内的样本提交后，数秒即可完成复刻并生成预览，保存后即可在文生音中使用。

我的数据安全吗？

音色、风格、历史记录等项目数据只保存在你的本地文档目录，不上传到 YiziVoice 自有服务器。调用 MiMo API 生成/识别时，文本或音频样本会发送给小米 MiMo 用于处理；API Key 存放在系统钥匙串，不写入任何文件。

升级后 API Key 为什么需要重填？

v2.0.1 起 API Key 不再以明文保存在本地文件，而是加密存入系统钥匙串：Windows 使用凭据管理器（DPAPI），macOS 使用 Keychain，Linux 使用 Secret Service（gnome-keyring / KWallet）。即使数据目录被整个拷走或上传网盘，也拿不到你的密钥。v2.1.3 起设置页只写不回显，保存后只显示「已配置」，可输入新 Key 替换或点「清除」删除。大多数情况下无需重填：旧版本 Key 会在首次启动时自动迁移；仅当从很老的版本跨级升级时需要重新输入一次。

AI 文本模型是什么？

它用于应用内的「AI 生成风格描述」和「AI 生成描述与试听文本」。设置中默认 mimo-v2.6-flash，点「获取模型」可列出当前 Key 可用的文本模型并选择。文本模型与 ASR 为付费模型，使用时需账户有余额。
