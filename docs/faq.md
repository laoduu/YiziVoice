# 常见问题（FAQ）

> 与官网 FAQ 同源维护；改动请两处同步（`website/index.html`）。

**Q：YiziVoice 收费吗？**
工具本身免费开源，仅需自备 MiMo API Key。MiMo-TTS 系列（文生音/克隆/设计）免费调用；MiMo-ASR 与 2.6 系列文本模型付费，需账户有余额。注册时填写邀请码 `DHLC96` 可额外获得体验金。

**Q：API Key 存在哪里？安全吗？**
只加密存储在本机系统凭据库（Windows 凭据管理器 / macOS Keychain / Linux Secret Service），不写入任何明文文件，也不会上传到任何服务器。设置页对 Key 只写不回显。详见 [SECURITY.md](../SECURITY.md)。

**Q：升级后 API Key 为什么需要重填？**
Key 一直存在系统凭据库，升级一般无需重填。仅从很老的版本（localStorage 时代）跨级升级时可能需要输入一次；旧版残留在配置文件里的明文会在首次启动时自动迁入凭据库。

**Q：数据存在哪里？可以迁移吗？**
本地 `文档/YiziVoice/`（配置、音色、历史记录），可在设置中重定向数据目录。删除该目录即恢复出厂状态。

**Q：支持哪些平台？**
Windows / macOS / Linux（AMD64）。Linux 推荐 deb 安装；AppImage 为实验性格式。详见 README 安装表。

**Q：克隆音色需要多长时间？**
录音或上传后确认即复刻，通常几秒内出结果。建议 20 秒以内的干净样本效果最佳。

**Q：为什么点「下载」在开发模式正常、装包后没反应？**
桌面 `tauri dev` 不注入 CSP，某些资源加载路径只在打包态暴露问题。这是本项目的已知特性，贡献者改动涉及下载/资源时必须装包验证（见 [pitfalls.md](pitfalls.md)）。

**Q：Linux 下无法切换中文输入法？**
从桌面正常终端启动应用即可（进程需要继承会话的 `GTK_IM_MODULE` / `XMODIFIERS` 环境变量）。若从缺少这些变量的脚本/agent 环境启动，输入法会失效。

**Q：历史记录能恢复到生成时的状态吗？**
能。点击历史条目「还原任务」，会完整装回生成时的模式、风格、文案，并把当时的音频放回工作台。
