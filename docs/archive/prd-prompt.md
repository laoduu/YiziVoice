# YiziVoice

我想使用MiMo-V2.5-TTS 系列语音合成大模型，开发一个桌面语音工具`YiziVoice`，主要功能是满足内容创作团队，在剪辑视频时需要各种音色配音的需求。主要功能点：

**音色克隆**
- 使用者在软件中，点击录音按钮，即可生成20秒以内的录音，确定后提交给`mimo-v2.5-tts-voiceclone`模型，进行复刻音色，并建立音色角色；
- 建立音色角色后，可以实现参数的微调&预览，实现更精细的音色调节；
- 后续文生音、音色转换等功能，可以选用音色角色。

**文生音**
- 使用者选择文生音功能，在文本框内填写或粘贴文案，选择音色，即可调用`mimo-v2.5-tts`系列不同的大模型（内置音色、文本定制音色、克隆音色等），进行文本转声音；
- 提供详细的微调参数，进行更精细的音色调节。

**音转文**
- 使用者选择音转文功能，点击录音，开始说话，即可调用`MiMo-V2.5-ASR`大模型，进行声音转文案。
- 提供详细的微调参数，进行更精细的转换效果控制。

**参数设定**
- API管理：用户可以管理自己的API
- 其他必要的设置项

**UI风格**
- 简洁、大气、优雅
- 液态玻璃风格面板式操作
- UI精细化，高精度UI，macOS风格

**Mimo大模型的开发者文档**
- 语音合成（MiMo-V2.5-TTS 系列）：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5
- 语音识别（MiMo-V2.5-ASR）：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/Speech-Recognition
