# YiziVoice — 设计灵魂

## 核心理念

为视频剪辑团队提供简单高效的语音生成工具，减少重复录音工作，提升内容生产效率。

## 设计原则

### 1. 简洁优先

界面保持简洁，功能分层展示。默认参数适用于大多数场景，高级参数可展开调节。

### 2. 即时反馈

语音生成过程提供实时进度反馈，生成完成后立即试听，减少等待焦虑。

### 3. 音色积累

通过语音克隆和个人音色库，让团队成员的音色可以复用，避免重复录制。

### 4. 本地优先

数据以 JSON 文件存储在本地（`文档/YiziVoice/`，可整体迁移），不依赖服务器。API 密钥由用户自行配置，存于系统钥匙串（Windows 凭据管理器 / macOS Keychain），工具本身不落明文。

## 技术选型理由

### Tauri 2 + React + Vite

选择 Tauri 是因为需要桌面应用的文件系统访问能力和系统级功能，同时复用系统 WebView2 而不捆绑浏览器内核——安装包因此从 v1.x 的 78MB 降到约 10MB。React 提供成熟的组件化开发模式，Vite 提供极速的开发体验。（早期版本的 Electron 实现已移除。）

### MiMo TTS API

小米 MiMo 模型在中文语音合成质量上表现优秀，且 API 兼容 OpenAI 格式，集成成本低。支持语音克隆是核心差异化功能。

### Tailwind CSS

本项目不需要花哨的 UI 库，Tailwind 提供足够的样式灵活性，且打包体积小。

## 用户体验考量

### 安装流程

- NSIS 安装器允许选择安装目录（非强制一键安装）
- 安装后首次启动自动检测运行环境，缺少依赖时给出明确提示和下载链接
- 安装包控制在 10MB 左右（WebView2 复用系统组件），下载快速

### 使用流程

- 打开即用，API 密钥配置在设置页面
- TTS 默认参数适合大多数场景，不需要反复调节
- 音色准备：录音 / 上传 / 文字设计 → 试听 → 保存为角色
- 支持音色导入导出，方便团队共享

### 历史记录

- 自动保存每次生成记录，用户无需手动操作
- 左侧栏内嵌历史列表设计，不占用主工作区空间
- 标题栏图标一键收起/展开，操作路径短
- 文生音记录显示音色名称标签，便于快速识别
- 支持「还原任务」回填，复用历史参数重新生成
- 删除前弹窗确认并提示「同时删除已生成文件」，防止误操作
- 提供「打开文件夹」按钮，方便用户在文件管理器中批量管理音频

### 错误处理

- 启动时检测关键文件和依赖，缺失时弹出清晰的错误提示
- API 调用失败时显示具体错误信息，而非通用的"请求失败"
- 网络异常时给出重试建议

## 未来方向（非承诺路线图）

- 批量文字转语音（多段文本一次生成）
- 音色效果对比（同一文本不同音色并排试听）
- 与剪辑软件集成（导出音频直接导入时间线）
- 历史记录搜索与标签分类
- 历史音频文件批量导出
